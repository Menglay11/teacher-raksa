Raksa's day

Connect the wish book.

One-time setup lets every visitor share a birthday wish and read the notes already left for Teacher Raksa.

  1. Create a Supabase project. Copy its project URL and publishable key from the project's Connect dialog or Settings → API Keys.
  2. In the project SQL Editor, create a new query and run the contents of supabase/schema.sql from this project. It creates the public wish book and the private administrator data tables.
  3. Copy .env.example to .env in the project folder. Fill in VITE_SUPABASE_URL and VITE_SUPABASE_PUBLISHABLE_KEY. A publishable key is safe for the website; never use a secret key here.
  4. Run npm install and npm run dev to open the invitation locally. To share it across devices, deploy the site and add those same two environment values to your host.

Admin setup is optional for the wish book. Names and wishes can be read by anyone who visits the invitation. See the project's README for more details.
